# SOCODECO — Premium Website

Cinematic multi-page website for SOCODECO (Société de Construction et de Développement du Congo), Kinshasa, DRC.

## Pages
Home (From Land to Landmark journey) · About/Our Story · General Construction · Engineering · Project Management · Architecture · Interior Finishing · Real Estate Development · Contact (on every page)

## Stack
Vite · React 18 · TypeScript · Tailwind CSS · GSAP ScrollTrigger · Lenis · Framer Motion. Multi-page build (one HTML entry per page). All hero/section films are custom-generated and self-hosted in `public/`.

## Develop
```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # production build to dist/
```

Legacy Next.js site assets are preserved in git history and `public/images/`.
